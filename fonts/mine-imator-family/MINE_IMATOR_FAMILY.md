# Mine-imator Family

This font was bootstrapped from `minecraft-ten` so the full character set works immediately.

Custom glyphs currently installed:
- `h.json` — custom H
- `o.json` — custom O

To add more Mine-imator-specific shapes later, replace the matching file in
`fonts/mine-imator-family/characters/`, then run `scripts/compile.bat`.

The font is registered in the root `fonts.json` as `mine-imator-family`.
